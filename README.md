# Um Lar Pra Eles — versão de produção (frontend)

## O que já está pronto
- Design responsivo mobile-first.
- Acessibilidade básica: skip link, labels, aria e navegação por teclado.
- SEO básico e Open Graph.
- Catálogo de animais com filtro e busca.
- Modal de perfil do animal.
- Formulário de interesse em adoção.
- Compartilhamento nativo quando disponível.
- Feedbacks/toasts.
- Estrutura visual para transparência financeira.
- Código separado em `index.html`, `styles.css` e `app.js`.

## Para colocar no ar
É um frontend estático e pode ser publicado em qualquer hospedagem de sites estáticos.

1. Substitua as fotos de demonstração por fotos reais.
2. Troque os textos, números e contatos.
3. No `app.js`, substitua o array `animals` por uma API/banco de dados.
4. Ligue o formulário a um backend seguro ou a um serviço de formulários.
5. Configure domínio, favicon e imagens Open Graph.
6. Não coloque chaves de API ou credenciais no JavaScript do navegador.

## Próxima etapa recomendada
Para uma operação realmente completa, criar:
- backend Node.js/Express;
- banco PostgreSQL ou Supabase;
- login de administrador;
- CRUD de animais;
- upload de imagens;
- status de adoção;
- leads do formulário;
- painel financeiro;
- geração de cards para redes sociais;
- integração com WhatsApp;
- logs e backup.

As fotos usadas neste protótipo são demonstrativas e vêm do Unsplash. Troque-as antes de publicar.
